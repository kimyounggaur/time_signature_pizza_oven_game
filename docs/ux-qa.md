## 표기

- `PASS`: 해당 열에 적은 방법으로 실제 실행해 기대값을 확인했다.
- `FAIL`: 실제 실행 결과가 기대값과 달랐다.
- `NOT_RUN`: 실행하지 않았다. 구현되어 있다는 사실만으로 통과시키지 않는다.
- `BLOCKED`: 구체적인 환경 제한 때문에 해당 실행을 완료할 수 없었다.

자동 검사 통과는 실제 브라우저 배치, 화면읽기, 기기 청취, 학습 효과의 인증이 아니다.
