# 구현 및 검증 기록

기준: 첨부 『박자표 피자 화덕』 설계서 v1.0 (2026-11-17). 작업일 2026-11-18.

| 단계 | 구현 |
|---|---|
| OV0 | 고정 여섯 줄 화면, 상태 모델, 버전 1 저장, 검사 러너 |
| OV1 | 분수 엔진과 C.1~C.3 참조 모델, 씨앗 39개·발견 4개 |
| OV2 | 실제 각도 판·도우·조각, 차례 놓기, 개별 빼기, 넘침·걸침 |
| OV3 | MIDI72 조각·MIDI60 자리 음, 잡음 클릭 3단, 예약 취소와 시계 중단 복구 |
| OV4 | 1선 리듬 줄·음표·묶음별 꼬리 잇기·악보 쪽지 |
| OV5 | 전체 주문 흐름, 두 번째 안내의 답, 다시 내기, 마감·지도·이어하기 |
| OV6 | 조건·묶음·다른 조합, 메뉴판 69칸, 엇박 선반·발견 다시 보기 |
| OV7 | 악보·소리 주문, 자유 화덕, 느리게·분할·음량·움직임 설정 |
| OV8 | 오프라인 SVG 아트, 타이머 '똑딱', 조작 안의 안내, 키보드·포커스·화면읽기 |
| OV9 | 아래 자동 검증 완료. 실제 브라우저·기기·강사·학습자 검수는 미완료 |

가게 이름은 타이틀 이름을 유지하고 보조 브랜드를 '똑딱 화덕', 캐릭터 이름을 '똑딱'으로 정했습니다(D10·D12 권장 범위). 그림은 평면 SVG와 조각별 토핑 무늬이며, 점음표는 바탕음표와 같은 색을 유지합니다. v1.1 이후 큰 판·섞임박자·리듬 받아쓰기·탭 채점은 포함하지 않습니다.

## 수행한 확인

- `npm test`: 101개 통과. 엔진 73, 전체 영업 흐름 12, 저장 7, 오디오 9.
- 39개 주문 전체의 가능한 채우기와 판정 일치, 12개 고르기의 답 유일성, 메뉴판 5+13+34+17=69칸.
- 다섯 영업일 모두 정답 경로와 안내/다시 내기 경로로 완료(순수 상태 모델). 최고 기록과 도장의 유지.
- 잘못된 저장·미래 버전 백업, 저장 금지 시 세션 유지, 메뉴판·엇박 선반 구분과 복원.
- 모의 Web Audio로 예약 시각·음높이·잡음 세기·전체 취소·0.8초 정지·출력 지연·화면 생략 검증.
- 페이지 자가검사: 실제 96/96 통과(Node에서 번들된 순수 모듈도 실행). 설계서의 원래 96개 검사와 일대일 동일한 인증표가 아니라 수행되는 96개 행동 검사입니다.
- 단일 HTML 생성 및 JavaScript 구문 검사. 약 156KB로 400KB 예산 이내. 런타임 외부 의존 없음.

## 검증하지 못한 항목

미리보기 서버는 기동했으나 CUA 브라우저가 로컬 미리보기 URL을 보안 정책으로 차단했습니다. 다른 브라우저 경로로 우회하지 않았습니다. 따라서 실제 DOM 렌더링, 일곱 화면의 스크롤·잘림·문구 줄 수·노드 생성·콘솔·터치 대상 크기는 브라우저에서 확인하지 못했습니다. CSS는 설계서의 320×568 기준 치수와 552px 미만 안내를 구현한 상태입니다.

실제 청취와 iOS/Android 음량·무음·백그라운드 복귀, 중급 폰의 60fps, 강사 이론 검수, 초등 학습자 사용성 확인도 수행하지 않았습니다. 이는 OV9의 사람·기기 확인 항목으로 남습니다. 자동 검사 통과를 실기기 검수 완료로 해석하지 않습니다.
